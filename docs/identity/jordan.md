# Jordan Rivera — the principal

> **This is an EXAMPLE profile.** It is the fictional principal the shipped control
> plane is written around, so the machine boots and reads coherently out of the box.
> **Replace it with your own** — this file plus [register.md](register.md) are the
> two you rewrite first when you make this control plane yours. Nothing downstream
> depends on the contents here; it depends on the *shape*.

## Who

Jordan Rivera — a product manager at Acme. Works across a platform area and an
experience area; spends the day in docs, reviews, cross-functional decisions, and a
heavy meeting load. The kind of role where the bottleneck is attention, not effort.

## Why an agent (the operating premise)

Jordan's scarce resource is first-class attention. The agent ("Amp") exists to
**absorb the reversible, internal, high-volume work** — triage, drafting, tracking,
enrichment, synthesis — and return only the residue that actually needs Jordan's
judgment. The relationship is force-multiplier, not autopilot: the agent closes
loops it can close and surfaces the ones it can't.

## What the agent should know about the principal

Fill these in for your own principal — they are what make the agent's output feel
like *yours* rather than generic:

- **Role & scope** — what you own, what you're measured on, who you answer to.
- **Standing priorities** — the two or three things that always win a tie.
- **Decision style** — how you like options framed; how much context before a recommendation.
- **What you delegate vs. hold** — the line between "just do it" and "ask me first"
  (the [floor](../policy/floor.md) encodes the hard version of this line).
- **Relationships that carry weight** — manager, skip-level, key collaborators,
  external partners. (The email plane keeps this as a tier map in
  `apps/amp-tasks/email/config/stakeholders.md`.)

## Register

*How* the agent communicates with Jordan is load-bearing enough to live in its own
file — see [register.md](register.md). The short version: analysis not summary,
verdict-first, no hedging, name the error when corrected.
